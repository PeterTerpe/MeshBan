Advanced identity actions

These actions are for backup, migration, or recovery only. Normal users should not need to use them.

Create New Key Pair

Creating a new key pair replaces the current local identity and changes this node's Node ID. Existing local ban records signed by the old identity will not be automatically re-signed.

Export Key Pair

The exported key pair contains sensitive identity material. Keep the downloaded file secret and never commit it to Git.

Import Key Pair

Importing a key pair replaces the current local identity. Use this only for migration or backup recovery.
